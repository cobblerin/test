# Cobblemon 포켓몬 납부 도감

| 설치 위치 | JAR |
| --- | --- |
| 전용 서버 `mods/` | [서버용 0.5.0](./cobblemon-donation-pokedex-server-0.5.0.jar) |
| 플레이어 클라이언트 `mods/` | [클라이언트용 0.5.0](./cobblemon-donation-pokedex-client-0.5.0.jar) |

서버와 클라이언트를 함께 0.5.0으로 업데이트하고 기존 도감 JAR을 교체하세요. Minecraft 1.21.1, Java 21, Fabric Loader 0.17.2 이상, Fabric API 0.116.6+1.21.1 이상, Cobblemon 1.8.4가 필요합니다. 도감은 인연시스템과 독립적으로 실행되며 기존 도감과 보상 수령 기록을 읽습니다.

서버가 포켓몬 소유권, 납부 가능 여부, 등록률, 보상 조건을 확인하고 포켓몬 차감·보상 지급을 처리합니다. 클라이언트는 HUD를 그리고 선택·확정·수령 요청을 보냅니다. 납부 도감은 등록률에 따라 아이템 보상을 지급합니다.

게임 채팅에서 **`/포켓몬도감`**을 입력하면 도감 HUD가 열립니다. 기존 명령어 `/donationdex`와 `/pokedex`도 사용할 수 있습니다. 상단에서 1~9세대를 바꾸거나 **납부 가능**과 **등록 완료** 필터를 선택하세요. 카드 목록은 화살표와 마우스 휠로 넘길 수 있습니다.

**납부 가능** 카드에서 파티·PC 개체의 모델, 레벨, 이로치 여부와 개체값을 확인한 뒤 한 마리를 선택하세요. 확인창에서 **납부 확정**을 누르면 해당 개체가 소모되고 종이 영구 등록됩니다. 폼과 이로치는 같은 종으로 집계합니다. 꺼내거나 목장에 맡긴 포켓몬은 회수하고 지닌 아이템을 빼야 납부 후보에 나타납니다.

| `gen4` | 4세대 107종 | 하이퍼볼 16개 |
| `gen5` | 5세대 156종 | 하이퍼볼 16개 |
| `gen6` | 6세대 72종 | 하이퍼볼 16개 |
| `gen7` | 7세대 88종 | 하이퍼볼 16개 |
| `gen8` | 8세대 96종 | 하이퍼볼 16개 |

보상은 **완성 보상** 메뉴에서 각각 1회씩 받을 수 있습니다. 1~9세대의 개별 100% 보상 9개와 합산 보상 4개가 모두 표시됩니다. 세대별 등록은 해당 세대와 합산 진행률에 동시에 반영됩니다. 인벤토리에 빈 칸 하나를 확보하세요. 전체 진행률은 전국도감 1,025종을 기준으로 계산합니다. 기본 Cobblemon에서 미구현 상태인 종도 포함하므로 서버에서 해당 종을 얻을 수 있게 해야 전체 100%를 달성할 수 있습니다.

첫 실행 후 `config/cobblemon_donation_pokedex/rewards.json`에서 보상별 `item`과 `count`를 바꿀 수 있습니다. 이전 버전에서 업데이트하면 기존 보상 설정과 수령 기록은 이어서 사용하며, 파일에 빠져 있던 `gen2`~`gen9` 항목만 기본값으로 추가합니다. 예를 들어 `"gen1": {"item": "minecraft:diamond", "count": 5}`로 설정하면 1세대 완성 보상으로 다이아몬드 5개를 지급합니다. 수량은 한 스택에 들어가는 범위만 허용하며 항목을 삭제하면 해당 보상을 비활성화합니다. 변경 내용은 보상 화면을 다시 열면 반영됩니다.

진행도는 월드의 `data/cobblemon_donation_pokedex/`에 저장됩니다. 납부 기록에는 차감한 개체 UUID가 포함됩니다. 서버가 Cobblemon 저장 전에 종료되어 해당 개체가 다시 나타나면 플레이어 접속 또는 도감 열기 시 같은 UUID를 확인해 납부를 마무리합니다. 수령 이력은 플레이어 인벤토리와 함께 Minecraft의 플레이어 데이터에 기록됩니다.

소스를 빌드하려면 JDK 21 및 Gradle 8.12.1 환경에서 이 디렉터리의 `gradle build`를 실행하세요. 결과물은 `build/libs/`에서 확인할 수 있습니다.
