# Cobblemon 포켓몬 납부 도감

Minecraft 1.21.1 **서버와 각 플레이어 클라이언트**의 `mods/`에 같은 [도감 JAR](./cobblemon-donation-pokedex-0.2.0.jar)을 넣으세요. 0.1.0을 설치했다면 기존 JAR을 0.2.0으로 교체하세요. Java 21, Fabric Loader 0.17.2 이상, Fabric API 0.116.6+1.21.1 이상, Cobblemon 1.8.4가 필요합니다. 도감은 자체 모드 ID·명령어·진행도·보상 설정을 사용하며 인연시스템 설치 없이 실행됩니다. 0.1.0에서 저장한 도감과 보상 수령 기록은 그대로 읽습니다.

게임에서 **K** 또는 `/donationdex`로 도감 HUD를 엽니다. `/pokedex`도 사용할 수 있습니다. K는 마인크래프트 조작 설정에서 바꿀 수 있습니다. 상단에서 1~9세대를 바꾸거나 **납부 가능**과 **등록 완료** 필터를 선택하세요. 카드 목록은 화살표와 마우스 휠로 넘길 수 있습니다.

**납부 가능** 카드에서 파티·PC 개체의 모델, 레벨, 이로치 여부와 개체값을 확인한 뒤 한 마리를 선택하세요. 확인창에서 **납부 확정**을 누르면 해당 개체가 소모되고 종이 영구 등록됩니다. 폼과 이로치는 같은 종으로 집계합니다. 꺼내거나 목장에 맡긴 포켓몬은 회수하고 지닌 아이템을 빼야 납부 후보에 나타납니다.

| 보상 설정 ID | 수령 조건 | 초기 보상 |
| --- | --- | --- |
| `gen1` | 1세대 151종 | 하이퍼볼 16개 |
| `total25` | 전체 257종 | 슈퍼볼 16개 |
| `total50` | 전체 513종 | 하이퍼볼 16개 |
| `total75` | 전체 769종 | 하이퍼볼 32개 |
| `total100` | 전체 1,025종 | 마스터볼 1개 |

보상은 도감의 **완성 보상** 메뉴에서 조건별 1회씩 받을 수 있습니다. 인벤토리에 빈 칸 하나를 확보하세요. 전체 진행률은 전국도감 1,025종을 기준으로 계산합니다. 기본 Cobblemon에서 미구현 상태인 종도 포함하므로 서버에서 해당 종을 얻을 수 있게 해야 전체 100%를 달성할 수 있습니다.

첫 실행 후 `config/cobblemon_donation_pokedex/rewards.json`에서 보상별 `item`과 `count`를 바꿀 수 있습니다. 예를 들어 `"gen1": {"item": "minecraft:diamond", "count": 5}`로 설정하면 1세대 완성 보상으로 다이아몬드 5개를 지급합니다. 수량은 한 스택에 들어가는 범위만 허용하며 항목을 삭제하면 해당 보상을 비활성화합니다. 변경 내용은 보상 화면을 다시 열면 반영됩니다.

진행도는 월드의 `data/cobblemon_donation_pokedex/`에 저장됩니다. 납부 기록에는 차감한 개체 UUID가 포함됩니다. 서버가 Cobblemon 저장 전에 종료되어 해당 개체가 다시 나타나면 플레이어 접속 또는 도감 열기 시 같은 UUID를 확인해 납부를 마무리합니다. 수령 이력은 플레이어 인벤토리와 함께 Minecraft의 플레이어 데이터에 기록됩니다.

소스를 빌드하려면 JDK 21 및 Gradle 8.12.1 환경에서 이 디렉터리의 `gradle build`를 실행하세요. 결과물은 `build/libs/`에서 확인할 수 있습니다.
