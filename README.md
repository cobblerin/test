# Cobblemon 교배 시스템

Minecraft 1.21.1, Fabric, Cobblemon 1.8.4용 교배·부화 모드입니다. 서버가 교배, 알 지급, 알걸음, 부화를 처리하며 클라이언트 모드는 선택 사항입니다.

## 설치

- 서버 `mods` 폴더에 `cobblemon-breeding-server-0.1.0.jar`를 설치합니다.
- PC 목장 패널과 중앙 알걸음 HUD를 쓰려면 접속할 게임 클라이언트의 `mods` 폴더에도 `cobblemon-breeding-client-0.1.0.jar`를 설치합니다.
- 클라이언트 모드 없이도 서버의 교배·부화 기능과 `/알걸음 <슬롯>` 명령은 작동합니다. 알걸음 결과는 채팅으로 표시됩니다.
- ZIP에는 서버와 클라이언트 JAR이 모두 들어 있습니다.

## 포함 기능

- 부모 타입에 맞는 블록을 목장 중심 같은 Y 높이의 9×9 범위에서 계산하고, 환경 점수에 따라 교배 시간을 20~60분으로 적용합니다.
- 목장마다 영양제를 최대 64개 보관하고, 자동 교배 및 금·은 모래시계를 지원합니다.
- 호환되는 부모 포켓몬과 부모별 최대 10회 교배 제한을 확인합니다.
- 완성 알은 파티, PC 순서로 지급하고 둘 다 가득 차면 목장에 보관합니다. 고유 지급 ID와 저장 상태로 재시도 중복을 방지합니다.
- 알걸음은 파티 알에만 적용됩니다. 파티 첫 슬롯의 불꽃몸은 진행을 2배로 하고, 알은 소환 및 레벨 상승이 차단됩니다.
- 종족별 기본 걸음 수는 Cobblemon egg cycles를 사용합니다. `config/cobblemon-breeding/egg-steps.json`에서 종족별 값을 지정할 수 있습니다.
- 부화 시 부모에게서 유전된 IV, 기술, 특성, 성격 및 폼 정보를 반영합니다. 볼 유전은 적용하지 않습니다.
- 정상 서버 종료 때 목장 상태와 플레이어 포켓몬 데이터를 저장합니다. 청크가 언로드된 목장은 진행을 멈춥니다.

## 명령어

- `/알걸음 <1-6>` 또는 `/eggsteps <1-6>`: 파티 슬롯의 알 부화 정보 확인
- OP 전용 `/교배관리` 또는 `/breedingadmin`: 목장 상태 및 진단 명령
